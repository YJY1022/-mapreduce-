# 无人机协作频谱感知仿真

## 概述

这是一个基于MATLAB的无人机协作频谱感知仿真代码，实现了过采样条件下的频谱感知算法。该仿真基于图片中提供的技术参数，模拟了多架无人机协作进行频谱感知的过程。

## 主要特性

- **过采样实现**: 采样率为200倍过采样 (N=200)
- **多无人机协作**: 支持多架无人机同时进行频谱感知
- **能量检测算法**: 实现了经典的能量检测频谱感知算法
- **协作决策**: 使用多数投票法进行协作决策
- **完整可视化**: 提供时域、频域和功率谱密度图

## 技术参数

根据图片中的要求配置：

- **载波频率**: 30.72 MHz (LTE 5G载波)
- **感知周期**: 6.5 μs
- **过采样率**: N = 200
- **过采样频率**: 30.77 MHz (基础频率 × 200)
- **无人机数量**: 4架
- **信噪比范围**: 0, 5, 10, 15, 20 dB

## 使用方法

1. 确保MATLAB已安装并包含信号处理工具箱
2. 运行主仿真文件：
   ```matlab
   run('uav_spectrum_sensing.m')
   ```

## 仿真流程

1. **参数配置**: 根据图片要求设置载波频率、过采样率等参数
2. **信号生成**: 生成QPSK调制的主用户信号（随机存在）
3. **多无人机接收**: 模拟不同无人机接收信号，包含信道衰落和噪声
4. **频谱感知**: 每架无人机独立进行能量检测
5. **协作决策**: 使用多数投票法融合各无人机的检测结果
6. **结果可视化**: 生成多种图表展示仿真结果

## 输出图表

仿真会生成包含6个子图的综合图表：

1. **时域图**: 接收信号的时间域波形
2. **频域图**: 信号的FFT频谱
3. **功率谱密度图**: 使用Welch方法计算的PSD
4. **能量检测结果**: 不同SNR下的能量级别
5. **检测性能比较**: 个体检测vs协作检测的性能
6. **过采样效果**: 过采样与正常采样的频谱比较

## 关键功能

### 过采样实现
```matlab
N_oversample = 200;     % 过采样率
fs = fs_base * N_oversample; % 过采样频率
```

### 能量检测算法
```matlab
signal_energy = sum(signal.^2) / length(signal);
threshold = 2 * noise_power;
detection = signal_energy > threshold;
```

### 协作决策
```matlab
votes = sum(detection_results(:, snr_idx));
cooperative_decision = votes > num_uavs/2;
```

## 参数调整

可以根据需要调整以下参数：

- `fc`: 载波频率
- `N_oversample`: 过采样率

- `SNR_dB`: 信噪比范围

- `T_sim`: 仿真时间长度
