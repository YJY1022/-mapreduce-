# UAV通信系统仿真代码

本项目实现了基于图片要求的UAV (无人机) 与基站通信系统的MATLAB仿真，重点关注过采样条件下的信号处理和分析。

## 系统参数

基于图片中的技术要求，系统采用以下参数：

- **载波频率**: 30.72 MHz (LTE-5G标准)
- **感知周期**: 63 μs
- **感知调度周期**: 200 (可调整)
- **过采样因子**: 2, 4, 8, 16 (可选择)
- **调制方式**: QPSK
- **信道模型**: LoS/NLoS (Rician/Rayleigh衰落)
- **功率参数**: 20 dBm发射功率, -174 dBm/Hz噪声功率谱密度

## 文件说明

### 1. `uav_communication_simulation.m`
**主要仿真脚本** - 完整的UAV通信系统仿真

**功能**:
- 生成QPSK调制的基带信号
- 应用Rician/Rayleigh信道模型
- 载波调制和解调
- 过采样信号处理
- 绘制时域图、频域图和功率谱密度图

**运行方法**:
```matlab
run('uav_communication_simulation.m')
```

**输出**:
- 6个子图的综合分析图
- 控制台性能统计
- 保存结果文件 `uav_simulation_results.mat`

### 2. `uav_parameter_analysis.m`
**参数分析脚本** - 比较不同过采样因子和信道条件的性能

**功能**:
- 测试多种过采样因子 (2, 4, 8, 16)
- 比较LoS和NLoS信道性能
- 生成SNR、EVM、PAPR、频谱泄漏的比较图
- 输出详细的性能分析报告

**运行方法**:
```matlab
run('uav_parameter_analysis.m')
```

**输出**:
- 性能比较柱状图
- 详细的性能分析表格
- 保存结果文件 `uav_parameter_analysis_results.mat`

### 3. `demo_uav_simulation.m`
**演示脚本** - 简化版本，便于快速验证和学习

**功能**:
- 简化的参数设置 (计算时间更短)
- 9个子图的详细分析
- 包含星座图和误差向量分析
- 实时性能统计

**运行方法**:
```matlab
run('demo_uav_simulation.m')
```

**输出**:
- 9个子图的综合分析图
- 控制台性能统计
- 保存结果文件 `demo_results.mat`

## 图表说明

### 时域分析
- **射频信号时域图**: 显示载波调制后的接收信号
- **基带信号时域图**: 显示I/Q分量的时域波形
- **星座图**: 显示QPSK符号的分布

### 频域分析
- **射频信号频谱**: 显示围绕载波频率的频谱分布
- **基带信号频谱**: 显示基带信号的频谱特性
- **功率谱密度**: 使用Welch方法估计的PSD

### 性能分析
- **SNR**: 信噪比计算
- **EVM**: 误差向量幅度
- **PAPR**: 峰均功率比
- **频谱效率**: bps/Hz
- **频谱泄漏**: 带外泄漏百分比

## 参数调整

可以通过修改以下参数来适应不同的仿真需求：

```matlab
% 系统参数
fc = 30.72e6;           % 载波频率
T_sense = 63e-6;        % 感知周期
oversample_factor = 8;  % 过采样因子

% 信号参数
data_rate = 1e6;        % 数据速率
P_tx = 20;              % 发射功率 (dBm)

% 信道参数
path_loss_los = 96;     % LoS路径损耗 (dB)
path_loss_nlos = 110;   % NLoS路径损耗 (dB)
K_factor = 10;          % Rician K因子 (dB)
```

## 结果解读

### 过采样的影响
- 更高的过采样因子提供更好的信号重建精度
- 但增加了计算复杂度和存储需求
- 建议根据精度要求选择合适的过采样因子

### 信道条件对比
- LoS信道通常提供更好的SNR和更低的EVM
- NLoS信道由于多径衰落导致性能下降
- Rician K因子影响LoS信道的性能
