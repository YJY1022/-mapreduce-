# UAV通信系统MATLAB仿真

基于技术文档中的参数和规格，实现了完整的UAV（无人机）通信系统仿真，包括严格的信号处理链路：**成型滤波 → 上变频 → 信道建模 → 下变频 → 匹配滤波**。

## 文件结构

- `run_uav_simulation.m` - 主仿真程序（推荐）
- `uav_config.m` - 参数配置文件
- `uav_communication_simulation.m` - 原始仿真代码（备用）
- `test_fixed_simulation.m` - 参数验证和测试脚本
- `verify_code.m` - 代码验证脚本

## 主要特性

### 1. 严格按照图片技术规格实现
- **载波频率**: 30.72 GHz（毫米波通信）
- **信道模型**: LoS（视距）路径损耗模型，参数A=9.6, B=0.16
- **调制方式**: QPSK（四相相移键控）
- **信号带宽**: 20 MHz
- **过采样处理**: 支持可配置的过采样倍数

### 2. 完整的信号处理链路
```
数据生成 → QPSK调制 → 成型滤波(RRC) → 上变频 → 信道传输 → 下变频 → 匹配滤波 → 符号恢复
```

### 3. 真实的UAV场景建模
- UAV高度、速度、距离的几何计算
- 多普勒频移效应
- 路径损耗和天线增益
- 高斯白噪声信道

### 4. 丰富的可视化分析
- **时域分析**: 各处理阶段的信号波形
- **频域分析**: 发射和接收信号的频谱
- **功率谱密度**: 信号的功率分布
- **星座图**: 调制质量分析
- **性能指标**: EVM、符号错误率等

## 使用方法

### 快速开始
```matlab
% 首先测试参数配置（推荐）
test_fixed_simulation

% 运行主仿真程序
run_uav_simulation

% 或运行原始完整仿真
uav_communication_simulation
```

### 自定义参数
编辑 `uav_config.m` 文件来修改仿真参数：

```matlab
% 修改载波频率
config.communication.fc = 28e9;  % 改为28 GHz

% 修改UAV高度和距离
config.geometry.uav_height = 150;    % 150米高度
config.geometry.distance_2d = 1000;  % 1000米水平距离

% 修改信噪比
config.channel.SNR_dB = 15;  % 15 dB信噪比
```

## 技术参数详解

### 信道建模
基于图片中的LoS信道模型：
```
路径损耗 (dB) = A × log₁₀(d) + B + 20 × log₁₀(fc/GHz)
```
其中：
- A = 9.6 (LoS路径损耗指数)
- B = 0.16 (环境因子)
- d = 3D距离 (m)
- fc = 载波频率 (Hz)

### 多普勒效应
```
fd = fc × v × cos(θ) / c
```
其中：
- v = UAV速度
- θ = 仰角
- c = 光速

### 信号处理参数
- **根升余弦滤波器**: 滚降因子 0.25
- **过采样倍数**: 4倍
- **滤波器长度**: 8个符号周期

## 修改和扩展

### 添加更多调制方式
在 `run_uav_simulation.m` 中修改调制部分：
```matlab
% 例如添加16QAM
constellation = [1+1j, 1-1j, -1+1j, -1-1j, 3+1j, 3-1j, -3+1j, -3-1j, ...] / sqrt(10);
```

### 添加多径信道
在 `uav_config.m` 中启用：
```matlab
config.simulation.enable_multipath = true;
```

### 修改频率和带宽
```matlab
config.communication.fc = 28e9;      % 28 GHz载波
config.frequency.bandwidth = 100e6;  % 100 MHz带宽
```

## 重要修复说明

### 已修复的内存溢出问题
原始代码存在采样频率计算错误，导致：
- **问题**: 采样频率 = 30.72 GHz × 4 = 122.88 GHz
- **结果**: 需要 900+ GB 内存，导致 MATLAB 无响应
- **修复**: 改为基带采样频率 = 1 MHz × 4 = 4 MHz
- **优化**: 内存使用降至 < 1 MB，大幅提升性能

### 参数优化
- 符号数从 1000 降至 500（降低计算复杂度）
- FFT 点数固定为 2048（避免动态内存分配）
- 窗口长度优化（功率谱密度计算）

## 注意事项

1. **内存优化**: 代码已优化内存使用，正常运行只需几MB内存
2. **参数合理性**: 修改参数时注意保持物理意义的合理性
3. **测试建议**: 运行 `test_fixed_simulation` 验证配置
